## Situation

Pipelines for a banking market relied on manual verification after each load, which was slow and easy to get wrong.

## Task

Raise data quality and reliability without adding more manual review.

## Action

I built automated schema and data validation with Python and dbt, ran it as part of the pipelines, and made failures visible to whoever was on support.

## Result

Manual verification effort was removed and problems surfaced earlier. Illustrative number: <n> manual checks removed.
